# prueba-Open-WebUI

> Inicialmente le das permisos de ejecucion a los script 


```bash


sudo chmod +x generar-carpeta.sh generar_env.sh


```

> Luego corres ambos script


```bash


sudo ./generar-carpeta.sh
./generar_env.sh ipia


```

```bash


sudo docker compose up -d
```
